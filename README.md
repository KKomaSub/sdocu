# 스도쿠 메이트 · Sudoku Mate

Cloudflare Pages용 스도쿠 게임입니다. 첫 방문에는 짧은 안내가 표시됩니다. 홈의 **혼자 풀기**는 300개 퍼즐 목록으로, **친구 대결**은 방 참가 및 생성으로, **월드 매칭**은 1:1 랜덤 대기열로 이어집니다. 퍼즐 진행, 사용자 퍼즐과 기록은 이전 버전과 같은 브라우저 저장 데이터를 사용합니다.

## Cloudflare Pages 배포

- 저장소 루트에 `index.html`, `assets/`, `manifest.webmanifest`를 둡니다.
- 빌드 명령은 `sh build.sh`, 출력 디렉터리는 `dist`입니다.
- Pages Functions는 루트의 `functions/api/`에 둡니다.
- 기존 D1 데이터베이스를 `MATCH_DB` 이름으로 바인딩합니다. 테이블은 첫 요청에서 초기화됩니다. `/api/match?health=1`로 바인딩을 확인할 수 있습니다.

`GET /api/match?count=1`은 만료되거나 짝이 정해진 등록을 제외한 매칭 대기 인원을 반환합니다. 방 탐지와 월드 매칭 인원 표시에 `MATCH_DB`를 사용합니다.

친구 방은 2~4인 개인전 또는 4인 2:2 팀전을 지원합니다. 정원이 차면 자동으로 카운트다운을 시작합니다. 팀은 무작위로 나뉘고 팀끼리 같은 판에서 풀이를 공유합니다. 방장이 대기 중이면 같은 공인 IPv4 또는 IPv6 /64 네트워크로 확인된 기기에 주변 방 안내가 표시됩니다. 안내에는 방 번호가 공개되지 않으며, 다른 네트워크에서도 번호나 초대 링크로 참가할 수 있습니다.

대전은 PeerJS 신호 서버와 WebRTC를 사용합니다. 인터넷 연결이 필요하며 일부 네트워크에서는 TURN 서버가 필요할 수 있습니다. 정적 파일만 열면 솔로 플레이를 확인할 수 있습니다. 대기열과 주변 방을 함께 확인하려면 Pages Functions와 D1이 동작하는 환경을 사용합니다.
