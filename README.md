# 스도쿠 메이트 · Sudoku Mate

Cloudflare Pages용 스도쿠 게임입니다. 첫 방문에는 짧은 안내가 표시됩니다. 홈의 **혼자 풀기**는 300개 퍼즐 목록으로, **친구 대결**은 방 참가 및 생성으로, **월드 매칭**은 1:1 랜덤 대기열로 이어집니다. 퍼즐 진행, 사용자 퍼즐과 기록은 이전 버전과 같은 브라우저 저장 데이터를 사용합니다.

## Cloudflare Pages 배포

- 저장소 루트에 `index.html`, `assets/`, `manifest.webmanifest`를 둡니다.
- 빌드 명령은 `sh build.sh`, 출력 디렉터리는 `dist`입니다.
- Pages Functions는 루트의 `functions/api/`에 둡니다.
- 기존 D1 데이터베이스를 `MATCH_DB` 이름으로 바인딩합니다. 테이블은 첫 요청에서 초기화됩니다. `/api/match?health=1`로 바인딩을 확인할 수 있습니다.

`GET /api/match?count=1`은 만료되거나 짝이 정해진 등록을 제외한 매칭 대기 인원을 반환합니다. 월드 매칭 인원 표시에 `MATCH_DB`를 사용합니다.

친구 방은 2~4인 개인전 또는 4인 2:2 팀전을 지원합니다. 정원이 차면 자동으로 카운트다운을 시작합니다. 팀은 무작위로 나뉘고 팀끼리 같은 판에서 풀이를 공유합니다. Android에서는 방장이 방에서 기다리는 동안 참가자가 친구 대결 화면을 열고 두 휴대폰의 뒷면을 가까이 대면 NFC로 번호가 입력됩니다. 방장은 NFC 카드 에뮬레이션을 지원해야 합니다. 웹이나 NFC가 없는 기기에서는 번호를 입력해 참가합니다.

대전은 PeerJS 신호 서버와 WebRTC를 사용합니다. 인터넷 연결이 필요하며 일부 네트워크에서는 TURN 서버가 필요할 수 있습니다. 정적 파일만 열면 솔로 플레이를 확인할 수 있습니다. 월드 대기열을 사용하려면 Pages Functions와 D1이 동작하는 환경을 사용합니다.

## Android

Android 8 이상에서 실행합니다. 퍼즐과 PeerJS는 APK에 포함됩니다. 월드 매칭 서버는 https://스도쿠.kro.kr 입니다. Google Mobile Ads와 UMP를 사용하며 디버그 빌드에는 테스트 광고 단위가 적용됩니다. 하트를 모두 쓰거나 힌트가 떨어지면 광고를 끝까지 볼 때마다 해당 보상을 하나씩 받을 수 있습니다.

JDK 17, Gradle 8.13, Android SDK 36 환경에서 `gradle -p android assembleRelease`로 빌드하고 APK를 배포용 키로 서명하세요.
